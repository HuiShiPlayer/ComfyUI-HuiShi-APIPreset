# 绘世玩家批量系统API预制 ComfyUI 插件
## 功能说明
1. 提供下拉选择API类型：文生图/图生视频/音频生成等全部预设类型
2. 参数输入框支持**模糊搜索**，输入关键词快速筛选参数（如输入“宽”自动匹配width【宽】）
3. 输出 ANY 通用类型，可连接任意节点任意参数输入位
4. 工作流导出API时，输出值固定为 `###{{[[xxx]]}}###` 占位符，适配批量API批量渲染

## 安装步骤
1. 打开 ComfyUI/custom_nodes/ 文件夹
2. 新建文件夹 `huis_player_api_batch`
3. 将4个文件放入文件夹内
4. 重启 ComfyUI，左侧节点栏「绘世玩家/API批量工具」找到节点

## 使用教程
1. 拖入节点，第一个下拉选择对应API类型（如文生图）
2. 在参数选择输入框输入关键词模糊检索，完整选择参数名称（width【宽】）
3. 将节点输出「api占位符输出」连接到对应节点参数（如分辨率width输入口）
4. 导出工作流API JSON，该参数会自动替换为 `###{{[[width]]}}###`

## 特性
- 兼容 Python3.8 ~ 3.12 所有ComfyUI版本
- ANY输出类型，支持数字、字符串、图片、视频所有参数通道
- 内置完整param配置，无需手动编辑
- 模糊检索快速定位长参数名（如name1【首帧|参考图1】输入“首帧”即可匹配）
